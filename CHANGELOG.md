# Release history

## v1.0 — 2026-10-09

- First public release of LAOS Analysis Software.
- Includes the Windows executable and its required `_internal` directory.
- Includes six selected HAAKE/TA example datasets and Chinese/English PDF manuals.
- Provides ten demonstration videos as downloadable release assets.
- Includes bilingual repository guides, a data manifest, citation metadata, and SHA-256 checksums.
- Includes SPP analytical/numerical modes and circular decomposition.

Existing example outputs are provided as reference files, not as newly recomputed validation results.
