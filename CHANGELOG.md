# Release History

## v1.01, 2026-10-22

- Replaces the previous Windows distribution with the v1.01 application package.
- Includes the corresponding raw HAAKE and TA example files in the Windows package and separate example-data download.
- Updates repository download links, installation instructions, citation metadata, and bilingual version references.

## v1.0, 2026-10-09

- First public release of LAOS Analysis Software.
- Provides a Windows x64 application package with the required runtime.
- Adds cleaned source code under `src/`.
- Adds browsable example data under `examples/Test Data/`.
- Includes six selected HAAKE/TA example datasets, Chinese and English PDF manuals, and ten demonstration videos.
- Adds CC BY 4.0 licensing, citation metadata, bilingual README files, and SHA-256 checksums.
- Includes SPP analytical/numerical modes and circular decomposition.

Existing example outputs are provided as reference files, not as newly recomputed validation results.
